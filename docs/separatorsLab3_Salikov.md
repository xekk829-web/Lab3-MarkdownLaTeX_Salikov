### Введение
Markdown — это облегчённый язык разметки текста, созданный в 2004 году Джоном Грубером и Аароном Шварцем. Он позволяет писать простой человекочитаемый текст, который с помощью специальных символов легко преобразуется в красиво оформленный HTML-код.
***
### Основные возможности Markdown
Основные возможности Markdown включают быстрое форматирование текста с помощью простых символов прямо во время ввода: создание заголовков разного уровня (через #), выделение слов жирным или курсивом, построение нумерованных и маркированных списков, а также удобную вставку гиперссылок и изображений. Для технических текстов язык предоставляет встроенные инструменты оформления цитат, создание аккуратных таблиц и, что особенно важно, выделение блоков кода с автоматической подсветкой синтаксиса для конкретных языков программирования.
___
### Пример форматирования
Заголовки:
# Заголовок первого уровня
## Заголовок второго уровня
### Заголовок третьего уровня
#### Заголовок четвёртого уровня
